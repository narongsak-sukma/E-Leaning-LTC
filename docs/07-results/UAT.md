## 1. การเตรียมสภาพแวดล้อมและบัญชีทดสอบ

### 1.1 ยก dev stack + seed ข้อมูล UAT

```bash
docker compose up -d                                   # dev stack (app :3000 · Kong :8000 · Mailpit :8025)
curl -sf localhost:3000/api/health >/dev/null && echo health=200

# seed บัญชี demo 8 บัญชี + หลักสูตร/ข้อสอบ UAT (idempotent — รันซ้ำได้)
UAT_DEMO_PASSWORD='<ตั้งรหัสเอง ≥12 ตัว>' bash scripts/uat-seed.sh
# หรือใช้รหัสที่บันทึกไว้ใน .env ของเครื่องสาธิต:
UAT_DEMO_PASSWORD="$UAT_DEMO_PASSWORD" bash scripts/uat-seed.sh
```

- รหัสผ่านชุดเดียวกันทุกบัญชี — สคริปต์พิมพ์ให้ครั้งเดียวท้ายการรัน · ไม่มีค่าจริงอยู่ใน repo (เก็บที่ `.env` = `UAT_DEMO_PASSWORD` · ดู `.env.example`)
- สคริปต์ดาวน์โหลดวิดีโอสาธิต 10 วินาที (Big Buck Bunny · © Blender Foundation · CC-BY 3.0) อัปโหลดเข้า bucket `media` ให้อัตโนมัติครั้งแรก — ถ้าเครื่องไม่มีอินเทอร์เน็ต บทเรียนวิดีโอจะเปิดได้แต่เล่นไฟล์ไม่ได้ (จดเป็นข้อจำกัด §5)
- รันซ้ำ = ตั้งรหัสผ่านใหม่ให้ทุกบัญชีตามค่าที่ส่งเข้ามา (แถวอื่นคงเดิม — fixed UUID + on conflict do nothing)

### 1.3 ข้อมูลหลักสูตร/ข้อสอบชุด UAT (ค้นหาด้วยคำ `[UAT]` ในระบบ)

| รหัส | ชื่อ | สถานะ | ผู้เห็น | เนื้อหา |
| --- | --- | --- | --- | --- |
| UAT-101 | [UAT] กฎหมายพื้นฐานสำหรับประชาชน | published | สาธารณะ | วิดีโอ 10 วิ → เอกสาร → ควิซ 2 ข้อ (ผ่าน 60% · ได้ 3 ครั้ง) · ไม่มีสอบปลายหลักสูตร |
| UAT-201 | [UAT] จริยธรรมทนายความ (มีสอบปลายหลักสูตร) | published | **ทนายเท่านั้น** | เอกสาร → วิดีโอ → สอบ EXAM-UAT-201 (3 ข้อ · 15 นาที · ผ่าน 60% · 3 ครั้ง · cooldown 30 นาที · ต้องเรียนจบก่อนสอบ) |
| UAT-DRAFT-001 | [UAT] หลักสูตรร่าง (รอเจ้าหน้าที่เนื้อหาเผยแพร่) | draft | เจ้าหน้าที่เท่านั้น | เอกสาร 1 บท — ใช้ทดสอบการเผยแพร่ใน UAT-05 |

เฉลยควิซ UAT-101 (ให้ผู้ทดสอบตอบถูกทั้งสองข้อ): (1) กฎหมายสูงสุด = **รัฐธรรมนูญ** (2) ผู้ถูกกล่าวหา = **บริสุทธิ์**จนกว่าคำพิพากษาถึงที่สุด
เฉลยสอบ EXAM-UAT-201 (3 ข้อ): รักษา**ความลับ**ของลูกความ · ปฏิบัติต่อศาลแบบ**เคารพและเที่ยงธรรม** · โฆษณาที่ไม่เหมาะสม = **อวดอ้างว่าชนะคดีแน่นอน**
กฎ credit: CR-UAT-201 = 6.00 จิตวิทยาจริยธรรม (ethics) เกิดอัตโนมัติเมื่อสอบผ่าน · CR-UAT-101 = 9.00 (general) ตั้งไว้ในทะเบียนกฎ — **หลักสูตรไม่มีสอบจึงไม่มีรายการ accrual อัตโนมัติ** (as-built: credit เกิดจากการสอบผ่านหรือเจ้าหน้าที่ปรับมือ — ดู §5.6)

### 1.4 ลำดับการทดสอบที่แนะนำ (มีการพึ่งพันกัน)

UAT-01 (citizen) → UAT-02 (lawyer สอบผ่าน) → UAT-03 (instructor) → **UAT-07 (registrar อนุมัติใบของ #1 + ออกใบประกาศให้ #2)** → UAT-04 (viewer) → UAT-05 (content) → UAT-06 (exam สาย) → UAT-08 (super_admin)
- ใบประกาศของ UAT-07 ต้องรอ UAT-02 สอบผ่านก่อน · การอนุมัติใบอนุญาตของ UAT-07 ต้องรอ UAT-01 ยื่นคำขอก่อน
- ทุกสคริปต์ทำแบบแยกบุคคลได้ ยกเว้นการพึ่งพันข้างต้น — หากทำพร้อมกัน ให้คนละบัญชีตามตาราง (ไม่แชร์บัญชี)
