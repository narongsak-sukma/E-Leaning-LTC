# คำอธิบายศัพท์ (Glossary) — LTC E-Learning

เวอร์ชัน 0.1.0 · 2026-09-08 · เอกสารทุกฉบับใช้ศัพท์ตามนี้

| ศัพท์ (TH)             | ศัพท์ (EN)                | ความหมายในระบบนี้                                                                 |
| ---------------------- | ------------------------- | --------------------------------------------------------------------------------- |
| หลักสูตร               | Course                    | หน่วยการเรียนที่เผยแพร่ ประกอบด้วยโมดูล บทเรียน และ (อาจมี) การสอบปลายหลักสูตร         |
| โมดูล                  | Module                    | กลุ่มบทเรียนในหลักสูตร มีลำดับ                                                   |
| บทเรียน                | Lesson                    | หน่วยเนื้อหาย่อย: วิดีโอ / เอกสาร / แบบทดสอบย่อย (quiz)                            |
| แบบทดสอบย่อย           | Quiz                      | ข้อสอบท้ายบทเรียน ไม่นับ credit โดยตรง (ช่วยเรียนรู้)                               |
| การสอบปลายหลักสูตร      | Final Assessment / Exam   | ข้อสอบรับประกาศนียบัตร มีกติกา (เวลา สุ่ม จำนวนครั้ง เกณฑ์ผ่าน)                      |
| ธนาคารข้อสอบ            | Question Bank             | คลังข้อสอบแยกตามหลักสูตร/หมวด ใช้สร้างชุดข้อสอบแบบสุ่ม                              |
| ประกาศนียบัตร           | Certificate               | เอกสารรับรองผลผ่านหลักสูตร มีรหัสอ้างอิง + QR สำหรับยืนยันสาธารณะ                   |
| เครดิต / หน่วยกิต       | Credit                    | หน่วยคุณวุฒิที่ได้จากการผ่านหลักสูตร (ค่าและเงื่อนไขกำหนดในกฎ)                      |
| Credit Bank            | Credit Bank               | ระบบสะสม/ติดตาม credit ของแต่ละบุคคลตามรอบต่ออายุ                                  |
| รอบต่ออายุ              | Renewal Cycle             | ช่วงเวลาต่ออายุใบอนุญาตว่าความ (ความยาวรอบ = config, ดู Q1)                          |
| กฎเครดิต               | Credit Rule               | กติกาการแปลงผลหลักสูตรที่ผ่าน → credit (จำนวน ประเภท อายุ credit)                 |
| บัญชีผู้ใช้             | Account / Profile         | ข้อมูลสมาชิกระบบ (แยกจาก auth identity)                                            |
| เลขที่ใบอนุญาต          | License Number            | เลขทะเบียนใบอนุญาตว่าความ ใช้ผูกบัญชีประเภททนายความ                                 |
| เจ้าหน้าที่             | Staff                     | ผู้ใช้งานฝั่งบริหารของสภาฯ (แยก sub-role: content / exam / registrar / viewer)     |
| นายทะเบียน             | Registrar                 | เจ้าหน้าที่ผู้อนุมัติ/ออกประกาศนียบัตรและยืนยันคุณวุฒิ                               |
| บันทึกตรวจสอบ           | Audit Log                 | บันทึก action สำคัญแบบ append-only ห้ามแก้/ลบ                                        |
| DCR                    | Document Change Request   | คำขอแก้เอกสารเมื่อโค้ดพบว่าเอกสารมีปัญหา (ไหล่ทาง CTO ตัดสิน)                        |
| RLS                    | Row-Level Security        | กลไก PostgreSQL จำกัดการเข้าถึงแถวข้อมูลตามบทบาท — เปิดทุกตาราง                    |
| BFF                    | Backend-for-Frontend      | ชั้น API ใน Next.js ที่ frontend เรียก แล้วสื่อสารกับ Supabase ด้วย service key ฝั่ง server |
| Wave                   | Wave                      | ช่วงงานของโครงการ (ดู PROJECT-STATE.md)                                             |
| DoD                    | Definition of Done        | เกณฑ์ว่างาน "เสร็จ" = lint+tsc+test+build ผ่าน + evidence + ผ่าน review             |
