ตรวจสอบประกาศนียบัตร

บริการสาธารณะสำหรับยืนยันความถูกต้องของประกาศนียบัตรที่ออกโดยระบบอีเลิร์นนิ่งของสภาทนายความแห่งประเทศไทย กรอกรหัสอ้างอิงที่ปรากฏบนประกาศนียบัตร หรือสแกน QR Code บนตัวเอกสาร

รหัสขึ้นต้นด้วย LTC- ตามด้วยปีที่ออกและหมายเลขลำดับ พิมพ์ให้ครบทุกตัว

สแกน QR Code บนประกาศนียบัตรจะเปิดหน้านี้พร้อมผลการตรวจสอบทันที โดยไม่ต้องพิมพ์รหัส

ไม่พบข้อมูลประกาศนียบัตร

รหัสที่กรอกไม่ตรงกับประกาศนียบัตรใดในระบบ กรุณาตรวจสอบการพิมพ์อีกครั้ง หากแน่ใจว่ารหัสถูกต้อง โปรดติดต่อฝ่ายวิชาการ โทร 0 2351 1128 (จันทร์–ศุกร์ 8:30–16:30 น.)

ข้อกำหนด PDPA: หน้านี้แสดงเฉพาะข้อมูลจำเป็นสำหรับการยืนยันความถูกต้องของประกาศนียบัตร (ชื่อ หลักสูตร วันที่ออก และหน่วยกิต) โดยไม่เปิดเผยข้อมูลส่วนบุคคลอื่น เช่น ที่อยู่ เบอร์โทร หรือประวัติการเรียน และไม่มีการเก็บประวัติการค้นหาของผู้ใช้บริการ

ทดลอง: กรอก เพื่อดูผล "ถูกต้อง" หรือ เพื่อดูผล "ไม่พบข้อมูล"
