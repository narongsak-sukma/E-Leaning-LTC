## 1. ทิศทางแบรนด์ (Brand Direction)

**โทน: "ทันสมัย – น่าเชื่อถือ – เป็นทางการ" (Modern · Trustworthy · Official)**

| แง่มุม       | ข้อกำหนด                                                                                                                               |
| ----------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| Purpose     | ให้ประชาชนและทนายความเชื่อระบบตั้งแต่หน้าแรก — ความน่าเชื่อถือเป็น *ฟังก์ชัน* ไม่ใช่แค่ความสวย |
| Tone        | สงบ มั่นคง อ่านง่าย — อ้างอิงคุณภาพโครงสร้างของ Coursera แต่ใช้สี/ตราสัญลักษณ์แบบสถาบันราชการไทย |
| Constraints | WCAG 2.1 AA, ภาษาไทยเป็นหลัก (วรรณยุกต์บน-ล่าง ต้องเผื่อ line-height), Tailwind CSS, รองรับ mobile-first responsive |
| Differentiator | ระบบ "สถานะ" ที่ชัดเจนทุกจุด (กริดข้อสอบ, credit meter, progress เรียน) + ตราสภาทนายความโทนทองบนน้ำเงินกรมท่าเป็นลายเซ็นของแบรนด์ |

**หลักการออกแบบ 5 ข้อ (ใช้ตัดสินใจทุกครั้งทนาย UI)**

1. **Clarity over decoration** — ตกแต่งเท่าที่สื่อสารโครงสร้าง/สถานะ ไม่ใช้ gradient ฉูดฉาดหรือ stock photo คนยิ้ม
2. **Status is always visible** — ทุก action มี feedback: บันทึกอัตโนมัติ, เวลาที่เหลือ, % ความคืบหน้า, สถานะอนุมัติ
3. **Calm density** — data-dense เช่น admin table ใช้ระยะห่างน้อยแต่อ่านได้; หน้าผู้เรียนใช้ระยะห่างมากขึ้น
4. **Thai-first readability** — line-height 1.6–1.7, ไม่ใช้ตัวเอียง (italic) กับข้อความไทย ใช้น้ำหนัก/สีแทน
5. **Trust cues** — ตราสถาบัน, ชื่อหน่วยงานเต็ม, วันที่-เวลา, รหัสอ้างอิงที่ตรวจสอบได้ แสดงในจุดที่ผู้ใช้ต้องตัดสินใจ

**สิ่งที่เลี่ยงอย่างเด็ดขาด (anti-patterns)**

- ม่วง-ฟ้าไล่เฉดบนพื้นขาวแบบ template ทั่วไป, มุมโค้งจัดเต็มทุกชิ้น, แสงเงาซ้อนหลายชั้น
- ฟอนต์ Latin-only แสดงไทยแบบ fallback (ตัวอักษรไม่ match)
- สีแดง/เขียวสดจัดกับพื้นขาวที่ contrast ไม่ถึง 4.5:1
- ปุ่ม/ธง "กดได้" ที่ไม่มี focus ring

- พื้นมืด (brand-800/900) ใช้ข้อความขาวหรือ `brand-200` เท่านั้น

## 3. Typography

### 3.1 ตระกูลฟอนต์ (Google Fonts, เปิดใช้ทุกหน้า)

| บทบาท            | ฟอนต์               | น้ำหนักที่ใช้          | เหตุผล                                                                 |
| ---------------- | ------------------- | ----------------------- | ------------------------------------------------------------------------ |
| หัวข้อ (heading) | **IBM Plex Sans Thai** | 600 (SemiBold), 700 (Bold) | โครงสร้างตัวอักษรทันสมัยแบบ engineering อ่านชัดในขนาดใหญ่ ให้ความรู้สึก "ระบบ/เทคโนโลยีที่เป็นทางการ" |
| เนื้อหา (body)   | **Sarabun**         | 400, 500, 600           | ฟอนต์ราชการไทยที่คุ้นเคย (ราชบัณฑิตยสภา) อ่านง่ายในขนาดเล็ก น้ำหนักกลางสวย |

```html
<link href="https://fonts.googleapis.com/css2?family=IBM+Plex+Sans+Thai:wght@400;500;600;700&family=Sarabun:wght@400;500;600;700&display=swap" rel="stylesheet">
```

Fallback stack: `Sarabun → IBM Plex Sans Thai → Tahoma → system-ui, sans-serif`

### 3.2 มาตราส่วน (Type Scale 1.25 · base 16px)

| Token      | ขนาด / line-height | น้ำหนัก          | การใช้งาน                          |
| ---------- | ------------------ | ----------------- | ------------------------------------ |
| `display`  | 39px / 1.3 (50.7)  | 700               | Hero หน้าแรก                         |
| `h1`       | 31px / 1.35        | 700               | ชื่อหน้าหลัก, ชื่อหลักสูตร         |
| `h2`       | 25px / 1.4         | 600               | ชื่อ section                        |
| `h3`       | 20px / 1.45        | 600               | หัวข้อ card, ชื่อบทเรียน           |
| `h4`       | 18px / 1.5         | 600               | หัวข้อย่อย, ชื่อตาราง              |
| `body-lg`  | 18px / 1.65        | 400               | คำอธิบายหลักสูตร, lead paragraph   |
| `body`     | **16px / 1.65**    | 400               | **เนื้อหาทั่วไป (ค่าเริ่มต้น)**     |
| `body-sm`  | 14px / 1.6         | 400               | helper text, ตาราง, sidebar        |
| `caption`  | 13px / 1.5         | 500               | ป้ายกำกับ, timestamp, ลิขสิทธิ์    |

> **หมายเหตุ line-height สำหรับภาษาไทย:** เนื้อหาไทยต้องการความสูงแถวมากกว่าอังกฤษเพราะวรรณยุกต์บน (อ้ ้ ๊ ๋) และสระล่าง (ุ ู) — body ใช้ 1.6–1.7 หัวข้อ 1.3–1.45 เป็นค่าต่ำสุดที่ยอมรับ ห้ามลดลงต่ำกว่านี้

### 3.3 กฎเฉพาะภาษาไทย

- ห้ามใช้ `italic` กับข้อความไทย (ตัวเอียงทำให้วรรณยุกต์ชนกัน) — เน้นจุดสำคัญใช้ `font-weight 600` หรือสี `brand-700`
- `text-wrap: pretty` กับย่อหน้าสำคัญ; ห้าม `text-justify` (ช่องไฟไทยเถิดเทิ่ง)
- ตัวเลข/รหัส อนุญาตให้ใช้ฟอนต์ tabular: `font-variant-numeric: tabular-nums` สำหรับ timer, คะแนน, ตาราง
- ตัวพิมพ์ใหญ่ (uppercase) ใช้กับภาษาอังกฤษเท่านั้น เช่น `WCAG`, `PDF`

## 4. Spacing / Radius / Shadow / Breakpoint

### 4.1 Spacing (base 4px — ใช้ scale ของ Tailwind)

| Token   | ค่า    | การใช้งานทั่วไป                                   |
| ------- | ------ | -------------------------------------------------- |
| `1`     | 4px    | ระยะ icon–ข้อความ, ช่องไฟภายใน badge              |
| `2`     | 8px    | padding แนวตั้งของ input, ช่องไฟระหว่างบรรทัดช่วย |
| `3`     | 12px   | padding ปุ่ม, ช่องไฟระหว่าง field                 |
| `4`–`5` | 16–20px | padding card, gap กริดหลัก                        |
| `6`–`8` | 24–32px | ระยะห่างระหว่าง section ในหน้า                   |
| `12`+   | 48px+  | ระยะ section ใหญ่ในหน้า public                   |

### 4.2 Radius

| Token   | ค่า     | ใช้กับ                                        |
| ------- | ------- | --------------------------------------------- |
| `sm`    | 6px     | badge, input, ปุ่มในตาราง, thumbnail เล็ก    |
| `md`    | 10px    | **ปุ่ม, input, select (ค่าเริ่มต้น)**        |
| `lg`    | 14px    | card, dropdown, modal                        |
| `full`  | 9999px  | avatar, chip, วง progress กลม, toast pill   |

### 4.3 Shadow (นุ่ม โทนน้ำเงิน ไม่ดำสนิท)

| Token   | ค่า                                                           | ใช้กับ                     |
| ------- | --------------------------------------------------------------- | ---------------------------- |
| `card`  | `0 1px 2px rgba(14,43,74,.06), 0 6px 20px rgba(14,43,74,.08)`  | card, table, sticky panel  |
| `pop`   | `0 12px 40px rgba(14,43,74,.18)`                                | modal, dropdown, toast     |
| focus   | `outline 3px solid #3375B5` + offset 2px (ไม่ใช่ box-shadow)   | ทุก interactive element   |

### 4.4 Breakpoint (ตาม Tailwind)

| ชื่อ  | ความกว้างขั้นต่ำ | พฤติกรรมหลัก                                              |
| ----- | ----------------- | ----------------------------------------------------------- |
| —     | < 640px           | คอลัมน์เดียว, sidebar → drawer, ตาราง → เลื่อนแนวนอน     |
| `sm`  | 640px             | ปุ่มเรียงแนวนอน, grid 2 คอลัมน์ (บางส่วน)                 |
| `md`  | 768px             | การ์ดหลักสูตร 2 คอลัมน์, ตารางแสดงครบ                    |
| `lg`  | 1024px            | **sidebar ถาวร** (learner/admin shell), เนื้อหา 2 คอลัมน์ |
| `xl`  | 1280px            | การ์ดหลักสูตร 3–4 คอลัมน์, KPI 4 ช่อง                     |
| `2xl` | 1536px            | คอนเทนเนอร์ `max-w-7xl` (1280px) กึ่งกลาง                 |

## 5. องค์ประกอบหลัก (Components)

> สูตรด้านล่างเป็น **Tailwind utility recipe** — ต้นแบบ HTML ทุกหน้าใช้สูตรเดียวกัน
> ทุก component ต้องมี `:focus-visible` ring จาก global style (ดู §10)

### 5.1 Button

**Variants**

| Variant  | พื้น            | ตัวอักษร | เส้นขอบ      | ใช้เมื่อ                          |
| -------- | ---------------- | --------- | ------------- | ---------------------------------- |
| primary  | `brand-600`      | ขาว      | —             | action หลักของหน้า (1 อัน/วิว)   |
| secondary| `#FFFFFF`        | `brand-700` | `brand-600` 1.5px | action รอง, คู่กับ primary     |
| ghost    | โปร่งใส         | `brand-700` | —             | toolbar, ปุ่มในแถบ action        |
| danger   | `danger-600`     | ขาว      | —             | ส่งข้อสอบ, ลบข้อมูล              |
| success  | `success-600`    | ขาว      | —             | ยืนยัน (confirm modal)           |

**ขนาด**

| Size   | padding          | ฟอนต์      | ใช้กับ                      |
| ------ | ---------------- | ------------ | ----------------------------- |
| sm     | 6px 12px         | 14px / 600   | ในตาราง, pagination        |
| md     | 10px 18px        | 16px / 600   | **ค่าเริ่มต้น**             |
| lg     | 14px 26px        | 18px / 600   | CTA hero, ลงทะเบียน        |

```html
<!-- primary -->
<button class="inline-flex items-center gap-2 rounded-[10px] bg-brand-600 px-[18px] py-2.5
  font-heading font-semibold text-white shadow-card hover:bg-brand-700 active:translate-y-px
  disabled:cursor-not-allowed disabled:bg-mist-200 disabled:text-ink-500">ลงทะเบียนเรียน</button>

<!-- secondary -->
<button class="inline-flex items-center gap-2 rounded-[10px] border-[1.5px] border-brand-600
  bg-white px-[18px] py-2.5 font-heading font-semibold text-brand-700 hover:bg-brand-50">ดูเฉลย</button>
```

**States:** hover = เข้มขึ้น 1 ระดับ; active = เลื่อนลง 1px; disabled = `mist-200` + `ink-500` + `cursor-not-allowed`; loading = spinner + ข้อความ "กำลังบันทึก…" + `aria-busy="true"`

### 5.2 Input + Validation (ข้อความไทย)

โครงสร้าง: `label (บนซ้าย, ต้องมีเสมอ)` → `input` → `helper text (ink-500)` หรือ `error (danger-600 + ไอคอน !)`

| State     | ขอบ input              | ข้อความช่วย                          |
| --------- | ----------------------- | -------------------------------------- |
| default   | `mist-300` 1.5px        | helper ปกติ `ink-500`                  |
| focus     | `brand-500` 2px + ring  | —                                      |
| error     | `danger-600` 1.5px      | "กรุณากรอกอีเมล" / "รูปแบบอีเมลไม่ถูกต้อง" |
| success   | `success-600` 1.5px     | (ใช้เฉพาะ field ที่ตรวจแล้ว เช่น เลขที่ใบอนุญาต) |
| disabled  | `mist-200` พื้น         | —                                      |

```html
<div>
  <label for="email" class="mb-1.5 block font-heading text-sm font-semibold text-ink-900">
    อีเมล <span class="text-danger-600" aria-hidden="true">*</span><span class="sr-only">(จำเป็น)</span>
  </label>
  <input id="email" type="email" required aria-describedby="email-err" aria-invalid="true"
    class="w-full rounded-[10px] border-[1.5px] border-danger-600 bg-white px-3.5 py-2.5
    text-ink-900 placeholder:text-ink-400" placeholder="name@example.com" value="ธนกร@">
  <p id="email-err" class="mt-1.5 flex items-center gap-1.5 text-sm text-danger-600">
    <svg ...><!-- ไอคอนวงกลมตกใจ --></svg> รูปแบบอีเมลไม่ถูกต้อง กรุณาตรวจสอบอีกครั้ง</p>
</div>
```

กฎ a11y: ทุก input มี `<label for>`; error ผูกด้วย `aria-describedby` + `aria-invalid`; ห้ามใช้ placeholder แทน label

### 5.3 Course Card (การ์ดหลักสูตร)

องค์ประกอบ: ปก 16:9 (SVG โทน brand ตามหมวด) → badge หมวด (มุมซ้ายบนของปก) → ชื่อหลักสูตร (h3, 2 บรรทัด) → metadata แถวเดียว (บทเรียน · ชั่วโมง · หน่วยกิต) → แถวล่าง: ระดับ + สถานะเปิดรับ + จำนวนผู้เรียน

```html
<article class="group flex flex-col overflow-hidden rounded-[14px] bg-white shadow-card
  transition hover:-translate-y-0.5 hover:shadow-pop">
  <a href="#" class="block focus-visible:outline-offset-[-3px]">
    <div class="relative aspect-video ..."><!-- SVG ปก + badge หมวด --></div>
    <div class="flex flex-1 flex-col gap-2 p-5">
      <h3 class="font-heading text-lg font-semibold leading-snug text-ink-900">กฎหมายที่ประชาชนควรรู้</h3>
      <!-- metadata: icon+ข้อความ 3 ชิ้น -->
    </div>
  </a>
</article>
```

การ์ดทั้งใบคลิกได้ (stretched link) — hover ยกขึ้น 2px + เงา `pop`

### 5.4 Progress Bar / Credit Meter

**Progress bar (ความคืบหน้าบทเรียน):** track `mist-200` สูง 8px มุม `full`; fill `brand-600`; ป้ายเปอร์เซ็นต์ `tabular-nums`; มี `role="progressbar"` + `aria-valuenow`

**Credit meter (ยอดสะสม vs เป้าหมายรอบต่ออายุ):** สูง 14–16px, มี marker เส้นเป้าหมาย; ค่า default — **12 หน่วย/รอบ 1 ปี** (SRS Appendix A · ธง Q1); สีตามสถานะ — `< 50%` = `brand-600` (ปกติ ไม่มีป้ายสถานะ), `50–84%` = `success-600` (ไม่มีป้ายสถานะ), `≥ 85%` = `success-600` + ป้าย "ใกล้ครบเป้า", `100%` = `success-600` + ป้าย "ครบเป้าหมายรอบ", `ใกล้หมดเวลารอบและยังไม่ครบ` = `warning-600`; ตัวเลข "8 / 12 หน่วย" ใช้ `tabular-nums` ขนาดใหญ่ — ห้ามติดป้ายสถานะ "ครบ" ก่อนถึง 100% จริง

```html
<div role="progressbar" aria-valuenow="67" aria-valuemin="0" aria-valuemax="100"
  aria-label="หน่วยกิตสะสมของรอบ 2569">
  <div class="h-3.5 w-full rounded-full bg-mist-200">
    <div class="h-3.5 rounded-full bg-brand-600" style="width:67%"></div>
  </div>
</div>
```

### 5.5 Table (Admin)

- หัวตาราง: พื้น `mist-100`, ตัว `ink-500` 14px 600, uppercase ไม่ได้ (ไทย) ใช้จุดไข่ปลาไม่ต้อง
- แถว: ขอบล่าง `mist-200`; hover `brand-50`; แถวที่เกี่ยว PII ห้าม copy ทั้งตารางโดยไม่ตั้งใจ (ใช้ `select-none` เฉพาะคอลัมน์รหัส)
- ตัวเลข/วันที่ ชิดขวาหรือ tabular; จำนวนแถวต่อหน้า 10–20 + pagination
- บน mobile: ครอบด้วย `overflow-x-auto` + `tabindex="0"` (ให้ scroll ด้วยคีย์บอร์ดได้)
- การเรียง (sort): ปุ่มในหัวตาราง + `aria-sort`

### 5.6 Badge (สถานะ)

| สถานะ       | พื้น           | ตัวอักษร      | จุดไข่ปลา |
| ------------- | --------------- | ---------------- | ----------- |
| ผ่าน / สำเร็จ | `success-50`    | `success-600`    | มี (จุด)   |
| รอตรวจ / รออนุมัติ | `warning-50` | `warning-600`    | มี         |
| ไม่ผ่าน / ผิดพลาด | `danger-50`  | `danger-600`     | มี         |
| กำลังเรียน    | `brand-50`      | `brand-700`      | มี         |
| เรียนจบ (ยังไม่สอบ) | `mist-100` | `ink-500`        | ไม่มี      |
| เกียรติยศ (ประกาศนียบัตร/หน่วยกิต) | `gold-100` | `gold-700` | ไม่มี |

```html
<span class="inline-flex items-center gap-1.5 rounded-full bg-success-50 px-2.5 py-0.5

```

### 5.7 Toast

มุมขวาล่าง (fixed), กว้าง ~360px, พื้นขาว + `shadow-pop` + แถบสีซ้าย 4px ตามชนิด; แสดง 5 วินาทีแล้วเลือน; มีปุ่มปิด (X) + `role="status"` / `role="alert"` (กรณี error); ห้ามเก็บ action สำคัญไว้ใน toast เพียงอย่างเดียว

ข้อความตัวอย่าง: "บันทึกคำตอบแล้ว (ข้อ 12/30)" · "บันทึกความคืบหน้าการเรียนเรียบร้อย" · "ส่งข้อสอบไม่สำเร็จ กรุณาตรวจสอบการเชื่อมต่อ"

### 5.8 Modal

- ฉากหลัง: ดำ 55% + `backdrop-blur-[2px]`; กล่อง: ขาว `rounded-[14px]` `shadow-pop` `max-w-lg`; อนิเมชัน fade+scale 150ms
- โครงสร้าง: หัวเรื่อง (h2) + เนื้อหา + แถวปุ่ม (ยกเลิก = ghost ซ้าย, ยืนยัน = primary/danger ขวา)
- a11y: `role="dialog"` `aria-modal="true"` `aria-labelledby`; กด Esc ปิด; focus วนในกล่อง (focus trap); เปิดแล้ว lock scroll; คืน focus ให้ปุ่มที่เปิด

### 5.9 Tab

แถบ tab มีขีดล่าง 2px (`brand-600`) ที่ tab active — ไม่ใช้กล่องสี; ตัว active `brand-700` 600, ไม่ active `ink-500` และ hover `ink-700`; `role="tablist"/"tab"/"tabpanel"` + `aria-selected` + ลูกศรซ้าย/ขวาเลื่อน tab

### 5.10 Breadcrumb

`หน้าแรก / หลักสูตร / กฎหมายสำหรับประชาชน / กฎหมายที่ประชาชนควรรู้` — แสดงไม่เกิน 4 ระดับ; หน้าปัจจุบัน `ink-700` ไม่เป็นลิงก์; `nav aria-label="เส้นทาง"` + `aria-current="page"`; บน mobile แสดงเฉพาะระดับสุดท้าย + ไอคอนย้อนกลับ

### 5.11 Pagination

ปุ่มกลม/มุมมน `sm`; หน้าปัจจุบันพื้น `brand-600` ตัวขาว `aria-current="page"`; ลิงก์ก่อน/หลังเป็นไอคอน chevron + ข้อความ "ก่อนหน้า/ถัดไป"; แสดงรูปแบบ `1 2 3 … 24`; ประกาศผลด้วย `nav aria-label="การแบ่งหน้า"`

### 5.12 Empty State

กล่องกึ่งกลาง: ภาพประกอบ/ไอคอนใหญ่ (48px, `mist-300`) + หัวข้อ ("ยังไม่มีหลักสูตรที่ลงทะเบียน") + คำอธิบาย 1 ประโยค + **ปุ่ม action นำทาง** ("เลือกชมหลักสูตร") — ห้ามปล่อยพื้นที่ว่างเปล่าโดยไม่บอกทางออก

### 5.13 Skeleton

บล็อก `mist-200` มุม `md` + shimmer (gradient เคลื่อนที่ 1.5s loop); ใช้กับ: การ์ดหลักสูตร (ปก+2 บรรทัด), ตาราง (แถว × 5), วิดีโอ (16:9); ต้องมี `aria-hidden="true"` และปิดด้วย `aria-busy` บนคอนเทนเนอร์; ห้ามกะพริบเร็วกว่า 300ms

### 5.14 Icon

- ระบบ: inline SVG stroke 1.8px, 20px (body) / 16px (dense), `viewBox="0 0 24 24"` สไตล์ Lucide
- สีตามบริบทข้อความ (`currentColor`); ไอคอนที่เป็น action เดี่ยว ต้องมี `aria-label` หรือ `sr-only` ข้อความ
- ไอคอนพื้นฐานที่ใช้บ่อย: search, clock, play, check, flag, download, file-text, video, award, user, users, bell, chevron-*, alert-triangle, shield, qr

### 7.1 หน้าสอบ (05-exam)

| หลักการ            | การนำไปใช้                                                                                     |

| ภาระรู้ระบบ        | กติกาสอบ (จำนวนข้อ เวลา เกณฑ์ ครั้งที่เหลือ) แสดงก่อนเข้าสอบ และซ้ำใน header แบบย่อ |

### 7.2 Credit Bank Dashboard (07)

- **ยอดสะสม vs เป้าหมายรอบ** เป็นการ์ดใหญ่ที่สุดบนแดชบอร์ด: ตัวเลข "8 / 12 หน่วย" + meter + ระยะเวลาที่เหลือของรอบ ("เหลือ 4 หน่วย · สิ้นสุด 31 ธ.ค. 2569") — ค่า default รอบ 1 ปี · 12 หน่วย (SRS Appendix A · ธง Q1)
- meter + ตัวเลข + ข้อความ สื่อพร้อมกัน (ไม่พึ่งสีเดี่ยว) — วางแนวโน้มรายปีเป็นแท่งเล็กถ้ามีข้อมูล
- ประวัติ credit เป็นตาราง append-only: วันที่ · หลักสูตร · หน่วย · รอบ · สถานะ — ผู้ใช้ควรเข้าใจได้ใน 5 วินาทีว่า "ยังขาดอีกเท่าไร ภายในเมื่อไร"
- ค่าเป้าหมาย/ความยาวรอบ มาจาก config (D3) — แสดงหมายเหตุ "ตามเกณฑ์ที่กำหนด" ไม่ hardcode ใน copy

### 7.3 เรียนต่อจากที่ค้าง (Continue Learning)

- การ์ดแรกของแดชบอร์ด: ชื่อบทที่ค้าง + % ความคืบหน้า + ปุ่มเดียว **"เรียนต่อจากที่ค้าง"** — ระยะทางจากแดชบอร์ดถึงวิดีโอ ≤ 2 คลิก
- lesson player จำตำแหน่งวิดีโอล่าสุด; บทเรียนถัดไปเปิดใช้ได้เมื่อปัจจุบัน "เสร็จ" (ดูครบ + ผ่าน quiz ถ้ามี)
- ทุกหน้าผู้เรียนแสดง % ความคืบหน้ารวมใน sidebar — ความคืบหน้าคือแรงจูงใจหลักของระบบ self-paced

## 8. Accessibility Checklist ต่อหน้า

รายการร่วม (ทุกหน้า): skip link · landmark (`header/nav/main/footer`) · `:focus-visible` ring · contrast ตาม §2.5 · `lang="th"` · ฟอนต์ ≥ 14px (ยกเว้น caption 13px ใช้กับ metadata ไม่ใช่เนื้อหา)

| หน้า                | รายการเฉพาะที่ต้องผ่าน                                                                                          |
| ------------------- | ----------------------------------------------------------------------------------------------------------------- |
| 01 home             | ฟอร์มค้นหามี label (sr-only ได้); การ์ดหลักสูตร link มีข้อความบอกชัด (ไม่ใช่ "ดู" เปล่า ๆ); ลำดับ heading h1→h2→h3 ไม่ข้ามขั้น |
| 02 auth             | ทุก field มี label จริง; error ผูก `aria-describedby` + `aria-invalid`; tab เข้าถึงด้วยคีย์บอร์ด; ข้อความแจ้งผลลัพธ์ `role="alert"` |
| 03 course detail    | accordion ใช้ `button aria-expanded` + `aria-controls`; ตารางโครงสร้างอ่านด้วย screen reader ได้; ปุ่มลงทะเบียน focus ชัดบน mobile |
| 04 lesson player    | วิดีโอมีปุ่มเล่น/หยุดที่ keyboard ถึงได้ + `aria-label`; sidebar nav มี `aria-current`; ปุ่ม "บทถัดไป" เป็นข้อความ ไม่ใช่ลูกศรเดี่ยว |
| 05 exam             | กริดข้อสอบ: ปุ่มบอกสถานะด้วย `aria-pressed` (ตั้งธง) / ข้อความ sr-only; timer เป็นข้อความ (ไม่ใช่ภาพ); modal ยืนยัน focus trap + Esc; เวลาเหลือน้อยแจ้งด้วยข้อความ ไม่ใช่สีอย่างเดียว |
| 06 exam result      | สถานะผ่าน/ไม่ผ่าน = ไอคอน + ข้อความ (ไม่ใช่สีเดี่ยว); ตัวเลขคะแนน `tabular-nums`; ปุ่มดาวน์โหลดบอกชนิดไฟล์และขนาด |
| 07 learner dashboard | meter มี `role="progressbar"` + ค่าเป็นข้อความ; ตาราง credit มี `<th scope="col">`; ลิงก์ "เรียนต่อ" บอกบทที่ค้างในข้อความ |
| 08 admin dashboard  | ตาราง scroll ได้ด้วยคีย์บอร์ด (`tabindex="0"`); ตัวเลข KPI มี label ครบ; ปุ่ม action ในตารางมี `aria-label` ระบุแถว |
| 09 certificate verify | แสดงเฉพาะข้อมูลจำเป็น (PDPA); ผลยืนยันประกาศด้วย `role="status"`; รหัสยืนยันอ่านออกเสียง/คัดลอกได้; ฟอร์ม 1 field + ปุ่ม — เข้าถึงง่ายบนมือถือ |

เกณฑ์ตรวจรับ: ผ่าน axe/Lighthouse ≥ 95 ด้าน accessibility + ทดสอบ keyboard-only (Tab/Esc/Enter) + ตรวจ 200% zoom ไม่พังเลย์เอาต์

## 9. i18n Notes (ไทย-first)

- โครงสร้าง string: คีย์แบบ namespaced `auth.login.title`, `exam.timer.remaining` — ค่าเริ่มต้นภาษาไทย พร้อม namespace `en` รองรับภายหลัง (BRIEF §6 next-intl-style)
- **ห้ามต่อข้อความ** (concatenation) — ใช้ parameter: `"exam.attempt.count": "ครั้งที่ {current} จาก {total}"`
- วันที่: `Intl.DateTimeFormat('th-TH', { calendar: 'buddhist' })` → "8 กันยายน 2569"; ตัวเลขใช้อารบิก (0–9) ตามแนวราชการ
- รหัสอ้างอิงประกาศนียบัตร (`cert_no`): รูปแบบ `LTC-<ปี ค.ศ.>-<เลขสุ่ม 6 หลัก>` เช่น `LTC-2026-483920` — ปีในรหัสเป็น ค.ศ. เพราะรหัสเป็นข้อมูลระบบ; **ปี พ.ศ. แสดงเฉพาะใน UI ตาม I18N-003** (รูปแบบรอยืนยันกับสภาทนายความ → U6)
- พหูพจน์/จำนวน: ภาษาไทยไม่ผันตามจำนวน — ระวังเมื่อเขียน `en` ให้ใช้ ICU plural ตั้งแต่ต้น
- คำศัพท์ใช้ตาม GLOSSARY.md เสมอ (เช่น "การสอบปลายหลักสูตร" ไม่ใช่ "final" ปนไทย; "หน่วยกิต (credit)" เต็มรูปแบบครั้งแรก หลังจากนั้น "หน่วยกิต")
- ข้อความ error เป็นภาษาที่ผู้ใช้เข้าใจ + บอกทางแก้ ("รูปแบบอีเมลไม่ถูกต้อง กรุณาตรวจสอบอีกครั้ง" ไม่ใช่ "invalid input")
- RTL ไม่อยู่ในขอบเขต แต่ห้ามใช้ `ml-/mr-` โดยไม่จำเป็น — ใช้ logical (`ms-/me-`) เพื่อความปลอดภัย
